# Antes de clicar

Panfleto digital educativo sobre phishing, prevenção e como agir após um golpe.

## Visualizar

Abra `index.html` no navegador. A página não requer instalação ou build.

## Publicar no GitHub Pages

Envie `index.html` e `.nojekyll` à raiz do repositório. Em **Settings → Pages**, selecione **Deploy from a branch**, branch **main**, pasta **/ (root)** e salve.

O conteúdo pode ser editado diretamente em `index.html`. As fontes oficiais estão no rodapé da página.
